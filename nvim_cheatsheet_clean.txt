 4. SEARCH & FIND (TELESCOPE)
================================================================================

  -------------------  --------------------------------------------------

  Space s g            Grep text in whole project
  Space s w            Grep the word under cursor
  Space s /            Grep in open files only

  Space s .            Recent files
  Space s r            Resume last search
  Space s d            Search diagnostics (errors / warnings)
  Space s h            Search help
  Space s k            Search keymaps  (use this when you forget a key!)

  INSIDE THE PICKER
  -------------------  --------------------------------------------------
  Ctrl+j / Ctrl+k      Move down / up in results
  Enter or Ctrl+l      Open selected item
  Ctrl+v / Ctrl+x      Open in vertical / horizontal split
  Ctrl+t               Open in new tab
  Ctrl+/ (i) or ? (n)  Show all keys for this picker
  Esc                  Close (or go to Normal mode inside picker)

  IN A BUFFER (built-in)
  -------------------  --------------------------------------------------
  /word                Search forward       (case-insensitive; type a

================================================================================
 13. BEHAVIOR SETTINGS THAT MATTER
================================================================================

  - Clipboard is shared with the system: y in Neovim = Ctrl+v in other apps.
  - Mouse works in all modes.
  - h / l / Left / Right / Backspace / Space wrap to the previous/next line.
  - Search ignores case unless you type a capital letter.
  - Leader sequences must be typed fast: 300 ms between keys.
  - Enter / o / O do not continue comments automatically.
  - Undo history is saved: u works even after reopening a file.
  - Yanked text flashes briefly.
  - Hyphen counts as part of a word (my-var is ONE word for w, b, *).
  - Wrapping is ON at startup (the last lines of options set wrap = true).

 14. VIM BASICS (FROM :Tutor)            plain Vim, works in every file
================================================================================

  FORMULA:   operator  [count]  motion          example:  d2w = delete 2 words
  Operators: d delete    c change    y copy (yank)
  Double it for a whole line:  dd   cc   yy        Count repeats:  2w  3e  5j

  MODES
  -------------------  --------------------------------------------------
  Esc                  Back to Normal mode (also cancels a half-typed key)
  i / a                Insert before / after the cursor
  A                    Append at end of line
  o / O                New line below / above, start typing
  R                    Replace mode (type over text) until Esc
  v                    Visual mode (select text)

  MOVE
  -------------------  --------------------------------------------------
  h  j  k  l           Left / down / up / right
  w / e                Next word start / end of word
  0 / $                Start / end of line
  gg / G               First / last line
  {n} G                Go to line n  (example: 25G)
  %                    Jump to matching ( ) [ ] { }
  Ctrl+o / Ctrl+i      Jump back / forward in position history
  Ctrl+g               Show file name and position

  DELETE / CHANGE / COPY
  -------------------  --------------------------------------------------
  x                    Delete character
  dw / de / d$         Delete to next word / end of word / end of line
  dd / 2dd             Delete line / 2 lines
  ce / c$              Change to end of word / end of line
  r{char}              Replace ONE character  (example: rx)
  yw / yy              Copy word / line
  v ... y              Select, then copy
  p / P                Paste after / before cursor
  u / U / Ctrl+r       Undo / undo whole line / redo

  SEARCH & REPLACE
  -------------------  --------------------------------------------------
  /text  ?text         Search forward / backward  (then n / N for next/prev)
  /text\c              Ignore case for this one search
  :s/old/new/g         Replace all on this line
  :5,10s/old/new/g     Replace on lines 5 to 10
  :%s/old/new/g        Replace in whole file
  :%s/old/new/gc       Whole file, ask yes/no for each

  FILES & SHELL
  -------------------  --------------------------------------------------
  :w / :q / :wq        Save / quit / save and quit
  :q!                  Quit and DISCARD changes
  :w NAME              Save as NAME
  :'<,'>w NAME         Save selected lines (select with v first)
  :r NAME              Insert file below cursor
  :r !ls               Insert command output below cursor
  :!cmd                Run a shell command  (:!ls)
  :e $MYVIMRC          Open your Neovim config
  :w ++p               Save and create missing folders
  :Tutor               Open the interactive tutorial

  OPTIONS
  -------------------  --------------------------------------------------
  :set ic / noic       Ignore case on / off        (invic = flip)
  :set hls is          Highlight matches / show while typing
  :nohlsearch          Remove search highlight

  HELP & COMMAND LINE
  -------------------  --------------------------------------------------
  :help  :help topic   Open help / help on a topic     (F1 also works)
  Ctrl+w Ctrl+w        Jump between windows (help <-> your file)
  Ctrl+d               In command line: list completions
  Tab / Shift+Tab      In command line: next / previous completion

  YOUR CONFIG CHANGES
  ------------------------------------------------------------------------
  x does not fill the register  |  p in Visual keeps your copied text
  Ctrl+d / Ctrl+u / n / N keep the cursor centered
  Search highlight is OFF by default  |  y / d / p use the system clipboard

 15. CONFLICTS & CONFIG FIXES  (read this!)
================================================================================

  KEY CONFLICTS
  ------------------------------------------------------------------------
  1. Space x          closes a buffer, but uv.nvim also uses Space x as its
                      prefix. Closing a buffer waits 300 ms. FIX: change the
                      uv prefix (e.g. to <leader>u) in the uv config.
  2. Space x s        close split (sec. 3)  vs  uv "run selection" (sec. 9).
                      Only one works. FIX: move one to another key.
  3. ] d / [ d        diagnostics (sec. 7)  vs  Treesitter "next/prev
                      conditional". Only one works. FIX: remove ]d/[d from
                      the Treesitter move keys.
  4. Space d          waits 300 ms because Space d s also exists.
  5. K                hover.nvim everywhere; Rust hover actions in Rust files.

  CONFIG FIXES NEEDED

    "})". Add the missing ")".

    commented out. Use  install(essential_parsers)  instead.
  - Treesitter text objects: with the main-branch plugin, keys in setup()
    may not be created. Set them with vim.keymap.set + select_textobject.
  - Telescope file: first line is "urn {" (should be "return {"), the closing
    "}" is missing, and the live_grep block must move inside pickers = {}.
