================================================================================
                          NEOVIM CHEAT SHEET (MY CONFIG)
================================================================================
 Leader key = <Space>      Local leader = <Space>
 Notation:  <C-x> = Ctrl+x   <S-x> = Shift+x   <leader> = Space   <CR> = Enter
 Modes:     n = Normal   i = Insert   v = Visual   s = Select

                            Type leader combos quickly, e.g. Space s n

--------------------------------------------------------------------------------
 15. VIM BASICS (FROM :Tutor)
--------------------------------------------------------------------------------
 Plain Vim keys. They work in every file, with or without plugins.

 THE FORMULA
 ---------------------------------------------------------------------------
 operator  [count]  motion          Example:  d2w = delete 2 words
 Operators:   d = delete    c = change    y = copy (yank)
 Double an operator to act on the whole line:  dd   cc   yy
 A count before a motion repeats it:  2w   3e   5j
 A motion alone just moves the cursor.

 MODES
 ---------------------------------------------------------------------------
 Esc               Back to Normal mode (also cancels a half-typed command)
 i                 Insert before the cursor
 a                 Insert (append) AFTER the cursor
 A                 Append at the END of the line
 o                 Open a new line BELOW and start Insert mode
 O                 Open a new line ABOVE and start Insert mode
 R                 Replace mode: typed text overwrites, until Esc
 v                 Visual mode (select text, then use d, y, c, :w ...)

 MOVE THE CURSOR
 ---------------------------------------------------------------------------
 h  j  k  l        Left, down, up, right
 w                 Start of next word
 e                 End of current word
 0                 Start of line
 $                 End of line
 gg                First line of file
 G                 Last line of file
 {n} G             Go to line n  (example: 25G)
 %                 Jump to the matching ( ) [ ] { }
 Ctrl+o            Jump back to older position
 Ctrl+i            Jump forward to newer position
 Ctrl+g            Show file name and cursor position

 DELETE
 ---------------------------------------------------------------------------
 x                 Delete character under cursor
 dw                Delete to start of next word
 de                Delete to end of word
 d$                Delete to end of line
 d2w               Delete 2 words
 dd                Delete whole line
 2dd               Delete 2 lines

 CHANGE (delete + Insert mode)
 ---------------------------------------------------------------------------
 ce                Change to end of word
 c$                Change to end of line
 r{char}           Replace ONE character with {char}   (example: rx)

 COPY, PASTE, UNDO
 ---------------------------------------------------------------------------
 yw                Copy a word
 yy                Copy a line
 v ... y           Select with Visual mode, then copy
 p                 Paste AFTER the cursor (or below, for lines)
 P                 Paste BEFORE the cursor (or above, for lines)
 u                 Undo
 U                 Undo all changes on the line
 Ctrl+r            Redo

 SEARCH
 ---------------------------------------------------------------------------
 /text <Enter>     Search forward
 ?text <Enter>     Search backward
 n                 Next match (same direction)
 N                 Previous match (opposite direction)
 /text\c           Ignore case for this one search
 Ctrl+o            Go back to where you were before the search

 SUBSTITUTE (find and replace)
 ---------------------------------------------------------------------------
 :s/old/new/              First "old" on the current line
 :s/old/new/g             All "old" on the current line
 :5,10s/old/new/g         All "old" on lines 5 to 10
 :%s/old/new/g            All "old" in the whole file
 :%s/old/new/gc           Whole file, ask yes/no for each one
 (select lines with v first, then type :s/old/new/g)

 FILES AND COMMANDS (type : then the command, then Enter)
 ---------------------------------------------------------------------------
 :w                Save
 :q                Quit
 :q!               Quit and DISCARD changes
 :wq               Save and quit
 :w NAME           Save the file under the name NAME
 :'<,'>w NAME      Save only the selected lines (select with v first)
 :r NAME           Insert the contents of file NAME below the cursor
 :r !ls            Insert the output of a shell command below the cursor
 :!ls              Run a shell command (any command: :!rm NAME)
 :e $MYVIMRC       Open your Neovim config file
 :w ++p            Save and create any missing folders
 :Tutor            Open the interactive tutorial

 OPTIONS (:set)
 ---------------------------------------------------------------------------
 :set ic           Ignore case when searching
 :set noic         Turn it off
 :set invic        Flip it (on <-> off)
 :set hls is       Highlight all matches + show matches while typing
 :nohlsearch       Remove the search highlight
 Rule: prefix "no" turns an option off, prefix "inv" flips it.

 HELP AND COMMAND-LINE COMPLETION
 ---------------------------------------------------------------------------
 :help             Open help        (F1 also works)
 :help topic       Help on a topic   (:help w   :help user-manual)
 K                 On a word: open its docs (in your config: hover.nvim)
 Ctrl+w Ctrl+w     Jump between windows (e.g. help window and your file)
 :q                Close the help window
 Ctrl+d            (after typing : and a few letters) List completions

 Ctrl+n / Ctrl+p   Same as Tab / Shift+Tab

 HOW YOUR CONFIG CHANGES THESE
 ---------------------------------------------------------------------------
 - x does NOT put the deleted character in the register.
 - p in Visual mode keeps your copied text (does not replace it).
 - Ctrl+d / Ctrl+u scroll half a page and keep the cursor centered.
 - n / N keep the cursor centered.
 - Search highlight is OFF by default (hlsearch = false).
 - Ctrl+q quits a file (same as :q).
 - Ctrl+s saves (same as :w).
 - y / d / p use the system clipboard (clipboard = unnamedplus).
 - Tab / Shift+Tab switch buffers in Normal mode (not completion).
